# SDY DORNOGOVI - QUIZ NIGHT ВЭБ СИСТЕМ

SDY (Social Democratic Youth) Дорноговь аймгийн "THINK LEFT - Ухаанаа Уралдуулах Үдэш" Quiz Night тэмцээний интерактив веб систем.

## 🚀 Хэрхэн ажиллуулах вэ?
1. `start.bat` файл дээр хулганаар хоёр дарж нээнэ.
2. Эсвэл `index.html` файлыг дурын вэб хөтөч дээр (Chrome, Edge, Firefox, Brave) нээж шууд ашиглана.
*(Интернет шаардлагагүй, бүх зураг болон дуу авиа бүрэн офлайн ажиллана).*

---

## 🎮 Хөтлөгчийн удирдлага & Товчлолууд
- **[Баруун сум ➔ / PageDown]**: Дараагийн асуулт / слайд
- **[Зүүн сум ⬅ / PageUp]**: Өмнөх асуулт / слайд
- **[Space (Зай авах)]**: Тоолдог цагийг эхлүүлэх / зогсоох (Play / Pause)
- **[S товч]**: Багуудын онооны самбарыг нээх / хаах
- **[M товч]**: Дуу авиа хаах / нээх (Mute / Unmute)
- **[F товч]**: Бүтэн дэлгэцээр проектор дээр гаргах (Fullscreen)
- **[Esc товч]**: Нээгдсэн цонх, самбарыг хаах

---

## 🏆 Онооны системийн боломжууд
- **Шууд оноо олгох**: Асуулт бүрийн доод талд байрлах багуудын нэр дээр дарж тухайн асуултын оноог шууд олгоно (+1, +2 оноо).
- **Баг нэмэх / Хасах**: `Онооны самбар` цэснээс хүссэнээрээ шинэ баг нэмж, багийн нэрийг засаж, шаардлагагүй багийг устгаж болно.
- **Оноо нэмэх / хасах**: Онооны самбар доторх `+` ба `-` товчоор хүссэн үедээ оноог гар аргаар залруулна.
- **Автомат хадгалалт**: Хөтөчийг хаасан эсвэл дахин ачаалласан ч оноо алдагдахгүй (LocalStorage-д хадгалагдана).
- **Төгсгөлийн Дүн & Тавцан (Podium)**: 1, 2, 3-р байрыг 3D тавцан, баярын салют (confetti), ялалтын фанфар аятайгаар харуулна.

---

## 📁 Файлын бүтэц
- `index.html` - Үндсэн нүүр хуудас
- `style.css` - Неон гэрэлтсэн харанхуй дизайн, хөдөлгөөнт эффектүүд
- `app.js` - Слайд шилжилт, тоолуур, онооны удирдлага, салют
- `audio-system.js` - Web Audio API синтезатор (Зөв, буруу, цаг дуусах, ялалтын ая)
- `quiz-data.js` - 4 үе шатны бүх асуулт, хариулт, тайлбарууд
- `assets/images/` - Эх танилцуулгаас ялган авсан бодит өндөр чанартай зургууд
